Especificar o stack tecnológico adotado para o desenvolvimento do MVP, garantindo que as ferramentas suportem o processamento de cálculos estatísticos e a usabilidade do sistema.

Frontend (Interface e UX):

HTML5 e CSS3: Estruturação e estilização base da plataforma.

JavaScript: Implementação de interatividade e manipulação dinâmica de dados no navegador.

Bootstrap: Framework para garantir a responsividade (acesso via desktop e mobile).

Backend (Lógica e Cálculos):

Python: Linguagem principal devido à sua eficiência no processamento de dados e bibliotecas matemáticas.

FastAPI ou Flask: Micro-framework para gerenciar as requisições do simulador e a lógica de negócio (cálculos de payback).

Banco de Dados e Infraestrutura:

SQLite / PostgreSQL: Armazenamento de tabelas tarifárias de concessionárias (ex: CPFL) e dados históricos de radiação solar.

Hospedagem Cloud: Utilização de serviços como Render, Vercel ou PythonAnywhere para publicação e disponibilidade do sistema.

Ferramentas de Versão e Gestão:

Git / GitHub: Controle de versão do código fonte e integração do trabalho da equipe.

Trello: Gestão de cronograma e metodologias ágeis (Kanban).
